## La leçon, pour toutes les prochaines

**Déposer le logo n'est pas une précaution : c'est la seule méthode qui marche.**
Trois essais sans lui, trois logos faux — « Behème Predaction », « Bukins Production »,
« Behême Production ». Un essai avec lui, un logo parfait.
