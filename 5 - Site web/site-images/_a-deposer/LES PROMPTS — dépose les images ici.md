## Comment on fait

Pour chaque image : dans Flow, tu déposes **l'image indiquée** (elle est ici, à côté),
tu colles le prompt, tu télécharges le résultat et **tu le déposes dans ce dossier**.
Le nom n'a aucune importance, je m'en occupe.

Format : **4:3** pour la première, **9:16** (vertical) pour la seconde.
